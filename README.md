# study_sync-ui

💬 Modern Chat UI
A modern high-fidelity frontend chat UI built using React and Tailwind CSS. This project aims at providing a high-end user experience with a responsive design, modern design, and clean component structure.

✨ Features
Responsive Design: Fully optimized for mobile, tablet, and desktop devices.

Interactive UI: Dynamic message display and sidebar navigation.

Modern Design: Designed using Tailwind CSS for a high-end look.

Clean Code: Clean component structure in React.js for easy scalability.

🛠️ Built With
Html
Tailwind CSS
React.js
